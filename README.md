# LEDGr

> A personal expense tracker for understanding where your money goes.

LEDGr is a personal finance application designed to track daily expenses, analyze spending habits, maintain transaction history, and keep track of money borrowed from or lent to other people.

The goal is to build a simple, practical financial record that I can use across both my laptop and mobile devices.

---

## 🚧 Project Status

**Currently in development.**

This project is being built as both a personal tool and a learning project to strengthen my skills in frontend development,  databases, and deployment.

---

## ✨ Planned Features

### 💸 Expense Tracking

- Add expenses with:
  - Amount
  - Category
  - Date
- Edit and delete expenses
- Categorize spending
- Track individual transactions

### 📊 Expense Analytics

View spending over different time periods:

- Weekly
- Monthly
- Annual

Analytics will include:

- Total expenditure
- Highest purchase
- Lowest purchase
- Most frequently used category
- Spending by category
- Number of transactions

### 📜 Transaction History

A dedicated history page containing all recorded expenses.

Planned functionality:

- View all transactions
- Sort transactions by date
- Filter by category
- Filter by date range
- Search transactions

### 👥 Borrowed & Lent Money

Track financial transactions with other people.

For each person, LEDGr will show:

- Money lent
- Money borrowed
- Money returned
- Money repaid
- Current balance
